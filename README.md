# COVID-19 Data Analysis & Visualization 📊

Progetto di analisi dati ed esplorazione delle metriche relative all'epidemia di COVID-19 basato su dataset giornalieri in formato CSV. Il progetto include script in Python per la pulizia, la manipolazione e la visualizzazione grafica delle informazioni.

---

## 📌 Descrizione

Questo repository contiene script in Python progettati per elaborare e analizzare i dati sull'andamento dei casi di COVID-19. L'obiettivo principali è estrarre insight significativi attraverso analisi statistiche e grafici riassuntivi.

---

## 📁 Struttura del Repository

```text
covid19_data_analysis/
│
├── COVID_01-01-2021.csv  # Dataset aggiornato a gennaio 2021
├── COVID_01-02-2021.csv  # Dataset aggiornato a febbraio 2021
├── COVID_01-03-2021.csv  # Dataset aggiornato a marzo 2021
├── Progetto_4.py         # Script principale di analisi e visualizzazione
├── LICENSE               # Licenza MIT
└── README.md             # Documentazione del progetto
🛠️ Tecnologie Utilizzate
Python 3.x

Pandas – Manipolazione e analisi dati

NumPy – Calcolo numerico

Matplotlib & Seaborn – Visualizzazione dei dati e creazione di grafici

🚀 Requisiti e Installazione
Clona la repository:

Bash
git clone [https://github.com/IronVin/covid19_data_analysis.git](https://github.com/IronVin/covid19_data_analysis.git)
cd covid19_data_analysis
Crea e attiva un ambiente virtuale (opzionale ma consigliato):

Bash
python -m venv venv
# Su Windows:
venv\Scripts\activate
# Su macOS/Linux:
source venv/bin/activate
Installa le librerie necessarie:

Bash
pip install pandas numpy matplotlib seaborn
💻 Esecuzione dello Script
Per eseguire l'analisi dati e generare i grafici:

Bash
python Progetto_4.py
